01 XNA lineage / modern GPU architecture

YotsubaFramework.Next Gen XNA.

Yotsuba Framework is the only XNA-based framework to completely modernize its graphics architecture, incorporating Compute Shaders, Vulkan on Android, WebGPU for the web and an ecosystem that supports seven shader languages. It also enables shader compilation at runtime.

03 Graphics APIs

Native APIs for every target.

Yotsuba keeps a familiar XNA-style surface while routing rendering work to the graphics API that belongs on each platform. No single legacy backend has to define the whole framework. Pick a target and follow the signal.
