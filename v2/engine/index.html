        Why Engine

        Made for people who love C#.

        Most engines ask you to learn their world first. This one starts from the language, the IDE and the libraries you already use.

        01

        Real C#, real tools

        Gameplay lives in C# scripts attached to entities. Debug with your IDE, add any NuGet package, and keep your own tooling.

        02

        Free means free

        Free and open source. No royalties, no per-install fees, no seat licences. The engine is code you can read.

        03

        No lock-in

        A project is ordinary .NET code plus .ytb files, which are readable JSON. If you outgrow the editor, you keep everything.

        04

        Your components show up

        The Inspector is built from component attributes and metadata, so the components you write appear in the editor without extra UI code.

        05

        Rebuild and Run

        Rebuild assets and relaunch the game from the editor menu, so the loop from an idea to a running build stays short.

        06

        XNA heritage

        Built on the XNA API that MonoGame, FNA and KNI developers know. Existing knowledge and the content pipeline carry over.

        In the box

        What's inside.

        2D

        • Sprites, transforms and a zoomable 2D camera
        • Depth ordering and off-screen culling
        • Animation, fonts, text and buttons
        • Tilemaps with Tiled (TMX) and TexturePacker sheets
        • Built-in 2D physics with debug drawing

        3D

        • Cameras, primitives and 2.5D sprites
        • glTF models with skeletal animation
        • PBR materials and custom shaders
        • Built-in 3D physics with a spatial broad phase
        • Particles and VFX, plus hardware occlusion queries

        Workflow

        • ECS with scenes, entities, components and systems
        • Editor: scenes, entities, console, history, color picker, 3D model editor
        • Scripting with your own systems
        • Keyboard, mouse, gamepad, touch and gestures
        • Audio with SFX and music channels

        Early-stage project: the API may still change. Everything above exists in the Yotsuba Hybrid codebase that the Engine is built on.

        The family

        Three products. One family.

        Same engine underneath, three ways in. Pick the one that matches how you like to work, and move to another when you need to.

        For code-first developers

        Framework

        A modern XNA-shaped library. Compute, Vulkan, Metal, DirectX 12, seven shader languages. You write everything in code.

        Explore Framework →         For tinkerers who want both

        Hybrid

        Framework plus engine. The editor lives inside your game window in DEBUG and is stripped from RELEASE.

        Explore Hybrid →         For creators · you are here

        Engine

        The classic experience: an editor app with a Play button, a content browser and one-click export.

        Roadmap

        From in-game editor to real app.

        The Engine's editor starts from the one Hybrid already has. Here is what it does today and what we are changing to make it feel like a proper engine.

        1. Project hubCreate or open a project from templates.
        2. Dockable panelsMove, tab and save your layout.
        3. Content browserThumbnails for sprites, models, sounds and shaders.
        4. Play in editorPlay, pause, step, and return to the edit state.
        5. Viewport gizmosMove, rotate and scale directly in the scene.
        6. Build & ExportOne dialog, one target list.
