Compute
Shaders

Push parallel work closer to the GPU without leaving the structure of an XNA-style framework.

Yotsuba Framework extends the familiar XNA programming model with modern GPU compute capabilities.

Compute shaders make it possible to process large amounts of data in parallel. That opens a practical path for effects, particle systems, procedural generation, image processing, lighting and physics calculations.

MGCB and MGFX support
with DesktopVK Profile

Keep the shader workflow you already know while Yotsuba handles the platform-specific graphics backend underneath.

Yotsuba Framework supports MonoGame effects compiled with the DesktopVK profile on Apple platforms through the Metal backend.

This gives existing projects a familiar content path: author effects in the MGFX and .fx workflow, build them through MGCB, and let Yotsuba provide the runtime translation to the target graphics API.

Capability / 07 · Web rendering 07

WebGPU
on the Web

Take the same XNA-shaped workflow to the browser through WebGPU, the modern graphics and compute API of the web.

WebGPU
  1. XNA-shaped C#
  2. Yotsuba
  3. WebGPU
  4. Vulkan · Metal · D3D12

WebGPU is the first browser API that gives the web real compute and explicit graphics.

The browser maps it onto Vulkan, DirectX 12 or Metal, depending on the platform. Yotsuba routes the same XNA-shaped project there, and MGFX, Slang, GLSL and HLSL shaders are all compatible with it.

07 / Why it mattersOne project, now reachable from a link: no install, no store, just a tab.

Games that open with a click

Share a build the way you share a web page. Compute shaders and modern rendering come along, because the browser exposes them natively.
