Yotsuba Hybrid combina el control total de un framework con las herramientas visuales de un engine. Desarrolla, ejecuta y distribuye gratis con MonoGame, KNI, FNA o Yotsuba Framework: los cuatro backends son open source. Elige en cada momento el que mejor se adapte a tus necesidades de compatibilidad y rendimiento.

En un proyecto Yotsuba Hybrid escribes tu lógica de juego una sola vez y decides con qué backend se ejecuta: MonoGame, KNI, FNA o nuestra propia reimplementación de alto rendimiento, Yotsuba Framework.

¿Cómo funciona?

El editor vive dentro de tu juego, no al lado.

En modo debug, Yotsuba Hybrid despliega un editor visual directamente en la misma ventana de tu juego — no una aplicación externa separada. Inspecciona, ajusta y edita mientras tu juego corre, en tiempo real.

mi-juego.exe — modo debug
01

Escribes tu juego

Código normal, sin ataduras a un editor propietario. Sigues siendo dueño de tu arquitectura.

02

Corres en modo debug

El editor visual aparece incrustado en la ventana del juego: sin apps separadas, sin contexto perdido.

03

Compilas en release

El editor desaparece por completo. Solo queda tu juego, corriendo sobre el backend que elegiste.

No es una app externa

El editor visual se muestra dentro de tu propio juego, en modo DEBUG — no una ventana separada.

Plataformas

Las plataformas se suman, no se reparten.

Como puedes elegir entre MonoGame, KNI, FNA o Yotsuba Framework para ejecutar tu juego, todas las plataformas soportadas por cualquiera de los cuatro quedan disponibles para tu proyecto Yotsuba Hybrid. Tú no gestionas nada: Yotsuba decide con qué compilar según lo que necesites en cada momento.

Σ

Todas las plataformas de MonoGame + KNI + FNA + Yotsuba Framework, disponibles desde una sola base de código. Sin trabajo extra de tu parte al cambiar de implementación. En consolas se requiere acceso a los programas, licencias y requisitos del fabricante.
