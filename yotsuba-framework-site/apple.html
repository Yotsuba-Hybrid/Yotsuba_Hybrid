01 XNA lineage / Apple-native path

MonoGame. Metal-native. On Apple.

Yotsuba Framework is an XNA-based refactor of FNA built to run MonoGame games through Metal on macOS, iPadOS and iOS — while keeping your existing MonoGame libraries in play.

02 / COMPATIBILITY

USE WHAT YOU ALREADY HAVE

Your MonoGame ecosystem doesn’t need a rewrite.

Reference libraries compiled for MonoGame and run them from Yotsuba Framework without rebuilding those libraries specifically for Yotsuba. The framework is designed around compatibility at the boundary, not around forcing an ecosystem reset.

05 Architecture

FNA roots.
Yotsuba direction.

Yotsuba Framework is a refactor of FNA with a different compatibility goal: preserve the XNA model, interoperate with the MonoGame ecosystem, and make Metal a first-class destination on Apple hardware.
