01 / QUICK START

Get a project running.

Yotsuba is designed to sit where an XNA-shaped game framework sits: your game owns the loop and content, while the framework supplies the platform and graphics implementation.

TERMINAL / SETUP
# Add the framework to your game project
dotnet add package Yotsuba.Framework

# Build content with the MonoGame pipeline
dotnet mgcb /@:Content/Content.mgcb

# Run the Apple target
dotnet run --project Platforms/Apple

Note: Package names and CLI entry points are placeholders while the public distribution is being finalized.

02 / PROJECT SHAPE

Keep the game portable.

Put game logic and shared assets in the core project. Keep the platform host thin, so the same code can move between desktop, mobile and future Yotsuba backends.

◆MyGame/
├─ MyGame.Core/ shared game code
├─ Content/ MGCB source and assets
├─ Platforms/Apple/ Metal host
└─ MyGame.sln
